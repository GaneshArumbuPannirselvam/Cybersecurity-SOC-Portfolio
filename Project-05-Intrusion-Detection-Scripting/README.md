# Project 5: Custom Intrusion Detection Scripting (HIDS Automation)
**Category:** Security Automation, DevSecOps, Endpoint Auditing  
**Core Technologies:** Python 3, Regex, Linux Systems, Security Event Logging (`/var/log/auth.log`)

---

## 1. Project Overview
Enterprise systems are continuously targeted by automated brute-force attacks aiming to compromise valid user credentials. While enterprise security tools exist, custom scripting provides flexible, lightweight telemetry tools to audit and defend standalone systems or isolated edge clouds. 

This project features a native **Python-based Host Intrusion Detection System (HIDS)** automation script designed to parse system authentication logs, extract threat intelligence vector fields using regular expressions (Regex), and instantly flag automated credential-stuffing patterns that breach corporate risk thresholds.

---

## 2. Technical Capabilities & Logic
The automation script (`auth_monitor.py`) works by executing the following operational steps:
1. **Target Log Auditing:** Automatically hooks into the native Linux OS authentication directory (`/var/log/auth.log`).
2. **Signature Analysis:** Loops through log entries line-by-line looking for targeted string triggers (`Failed password for`).
3. **Regex Extraction:** Utilizes Python's `re` module to locate and isolate the source IPv4 strings from unformatted system text.
4. **Threshold Alerting:** Utilizes a hash-map counter baseline. If any singular IP address registers \(\ge 5\) separate authentication drops, a critical security event is immediately printed to the terminal console.

## 3. How to Deploy & Run the Tool

### Prerequisites
* Linux environment (Ubuntu/Debian) or access to historic Syslog files.
* Python 3.x installed natively.

### Execution Instructions
1. Download or clone this directory onto your target endpoint machine.
2. Grant execution privileges to the automation file:
   ```bash
   chmod +x auth_monitor.py
   ```
3. Run the script with necessary read access elevations:
   ```bash
   sudo ./auth_monitor.py
   ```

## 4. Corporate Integration & Real-World Application
In a production corporate environment, this script serves as a baseline prototype for automation workflows:
* **SIEM Offloading:** Lightweight scripts can run as localized daemons directly on servers to block attacks at the root layer, reducing the need to send gigabytes of raw, unparsed log noise to an expensive central SIEM engine like Splunk.
* **SOAR Automated Playbooks:** The terminal outputs generated by this script can be easily piped directly into a local firewall API (such as adding an immediate block rule to an edge **pfSense appliance** or Linux IPTables boundary) to execute fully automated threat mitigation playbooks.
